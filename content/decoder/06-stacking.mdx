A decoder is the same block stacked N times, and the residual stream is what runs up the stack. Below, one position's stream gains an attention update and a feed-forward update in each block; after the embedding and after every block, the "logit lens" applies the final LayerNorm and output head early, to show which next character the stream would predict if the model stopped there.

With the random weights used here, each block's update is only about 1% of the stream, so the lens hardly moves from layer to layer. In trained models the read-out typically sharpens towards the final prediction as the layers go by; the idea and the name come from ["interpreting GPT: the logit lens"](https://www.lesswrong.com/posts/AcKRB8wDpdaN6v6ru/interpreting-gpt-the-logit-lens). This model ties its output head to the embedding table and ends with a single LayerNorm, so the lens is exactly the model's own read-out, applied early.

<Layer kind="concept">

A real Transformer doesn't run one block — it runs **N** of them, with
the output of block `i` becoming the input of block `i + 1`. GPT-3 has
96 of these stacked. Each block looks identical from the outside (the
same dimensions in and out) but learns to specialise.

What changes layer to layer? Two things, mostly:

1. **The information available**. Block 0 sees raw token + position
   embeddings. By block 5, every position's vector has already been
   mixed with every previous position's vector five times. Higher blocks
   get to operate on much richer features.
2. **The attention pattern**. Empirically, early blocks tend to attend
   locally (a few tokens back), middle blocks pick up syntactic
   relationships, and late blocks integrate longer-range semantic
   structure. With our random toy weights you won't see those clean
   layers, but you _will_ see distinct patterns block to block.

<Layer kind="maths">

If we name a block's transformation $B$, then a stack of $N$ blocks is
just function composition:

$$
\operatorname{forward}(x) = B_{N-1}\big(B_{N-2}(\cdots B_0(x) \cdots)\big)
$$

…with a final LayerNorm and the output projection at the end. The
_residual stream_ — the running vector at each position — is the link
between blocks. Each block reads the stream, computes a contribution
(via attention and the FFN), and adds the contribution back.

$$
\begin{aligned}
x_0 &= E[\text{ids}] + PE && [S, d_{\text{model}}] \\
x_{n+1} &= B_n(x_n), \quad n = 0, \dots, N-1 \\
y &= \operatorname{LN}(x_N)\, E^{\top} && \text{tied output head, } [S, V]
\end{aligned}
$$
