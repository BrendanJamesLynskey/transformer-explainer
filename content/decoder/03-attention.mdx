Attention is computed one query row at a time. Below, one row of the pattern is built exactly as the code builds it: a dot product with every key, a scale, the causal mask, a softmax in three steps, and a weighted sum of the value rows; then it moves on to the next row, and at the end the heads are joined and projected.

<Layer kind="concept">

**Attention** is how the decoder looks back at earlier tokens. For every
position `i`, it asks: "given what I'm computing here, which earlier
positions matter, and how much?"

The trick is that we never compute "look back at position `j`" by
hand-coding it. Each position broadcasts three vectors:

- a **query** — what this position is asking about,
- a **key** — what this position can answer with,
- a **value** — what this position has to offer.

Then for every pair (query at `i`, key at `j`) we compute a similarity
score (dot product). Apply a softmax across the row, and you have a
probability distribution over which positions to read from. Take the
weighted average of their **values**, and that's the attention output.

<span id="d-mask" />

To keep the decoder _causal_ — so position `i` can only see positions
`≤ i` — we add a "mask" that pushes future scores to `−∞` before the
softmax. Future weights end up at zero.

the toy decoder. Hover any query row in the scores or weights matrix to
highlight the keys it pays attention to.

<span id="d-scale" />

For a single head with head dimension $d_{\text{head}} = d_{\text{model}} / n_{\text{heads}}$:

$$
\begin{aligned}
Q &= X W_q, \quad K = X W_k, \quad V = X W_v && [S, d_{\text{head}}] \\
\text{scores} &= \frac{Q K^{\top}}{\sqrt{d_{\text{head}}}} && [S, S] \\
\text{weights} &= \operatorname{softmax}(\text{scores} + M) && \text{each row sums to } 1 \\
\text{output} &= \text{weights} \cdot V && [S, d_{\text{head}}]
\end{aligned}
$$

where $M$ is the causal mask: $M_{ij} = 0$ for $j \le i$ and $-\infty$ for
$j \gt i$, so position $i$ can never attend to a later token.

**Multi-head attention** runs $H$ of these in parallel on disjoint
slices of $d_{\text{model}}$, concatenates the per-head outputs, and projects
through $W_o$:

$$
\begin{aligned}
\text{head}_h &= \operatorname{Attention}\!\left(X W_q^{(h)},\, X W_k^{(h)},\, X W_v^{(h)}\right) \\
\text{output} &= \left[\text{head}_0 \,\|\, \text{head}_1 \,\|\, \cdots \,\|\, \text{head}_{H-1}\right] W_o && [S, d_{\text{model}}]
\end{aligned}
$$

<span id="d-heads" />

Each head can specialise in a different relationship — one might track
which token came right before, another which token shares an opening
parenthesis, and so on. This toy model, trained on one book, learns
simple habits: in block 1 both heads look mostly at the current letter
and the one before it, and in block 2 one head sends each space back to
the start of the window (the landing page shows all four heads). Switch
any widget's weights to random init to see where training started: rows
spread almost evenly.

<Layer kind="code">

The attention head, in TypeScript, is shorter than its description:

```ts
// src/lib/transformer/attention.ts (excerpt)
export function singleHeadAttention(Q, K, V) {
  const seqLen = Q.length;
  const d_head = Q[0]?.length ?? 0;
  const scale = 1 / Math.sqrt(Math.max(1, d_head));

  const Kt = transpose(K);
  const raw = matmul(Q, Kt);
  const scores = raw.map((row) => row.map((v) => v * scale));

  const mask = causalMask(seqLen); // -Inf above diagonal
  const weights = softmaxRows(scores, mask); // row-wise stable softmax
  const output = matmul(weights, V);
  return { scores, weights, output };
}
```

Multi-head simply slices the model dimension into `n_heads` groups, runs
`singleHeadAttention` on each, concatenates, and projects through
`W_o`. The widget above hits `/api/compute/attention`, which calls the
exact function `verify-maths` checks against the PyTorch fixtures.

<Remember>

- Each position asks with a query, answers with a key and offers a value; a score is $q \cdot k / \sqrt{d_k}$.
- The causal mask sets future scores to $-\infty$, so a position sees only itself and what came before.
- A softmax turns each row of scores into weights that sum to 1; the output is the weighted sum of the values.
- Multi-head attention runs several heads on slices of $d_{\text{model}}$, joins them and projects with $W_o$.
